bulk processing, analytics and detailed logging.

== Description ==

OptiPress optimizes your entire Media Library with real, verifiable compression.
Every statistic in the dashboard is computed from actual file-size deltas — nothing
is simulated.

* Lossless/balanced/lossy compression via Imagick (preferred) or GD
* WebP and AVIF generation for full sizes and all intermediate sizes
* Auto-serving via <picture> tags — compatible with Gutenberg, WooCommerce,
  Elementor, Divi, Avada, Oxygen and full-page caches (WP Rocket, LiteSpeed,
  W3 Total Cache, WP Super Cache, Autoptimize)
* Resumable bulk optimization with live progress, safe for 50,000+ images
* Original backups + one-click restore
* Analytics with time ranges, full event logs, retry workflows
* Server capability diagnostics with human-readable explanations

== Installation ==

1. Upload the `optipress` folder to `/wp-content/plugins/`.
2. Activate OptiPress.
3. Open OptiPress → Bulk Optimize → Start Optimization.
